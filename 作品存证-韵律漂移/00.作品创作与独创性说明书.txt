一、作品概述
────────────
  《韵律漂移（Harmonic Drift）》是一款 100% 原创的「节奏 × 物理 × 策略」
  混合玩法电子游戏。作品以 Web 前端标准技术（HTML5 Canvas + JavaScript +
  Web Audio API）实现游戏核心引擎与画面渲染、音乐合成，并基于 Android SDK
  使用原生 WebView 封装为可独立安装的 Android 客户端（APK），在智能手机
  或平板电脑上运行。

  本作品可在任何主流现代浏览器中直接打开游玩，也可作为 Android 8.0 及以上
  系统的原生应用安装运行，双端内容完全同源、玩法与体验一致。


二、独创核心玩法机制（权利要求创新点）
──────────────────────────────────
  本作品在节奏游戏领域引入了以下原创玩法融合设计，属作者独立构思、市场上
  不存在相同或近似的既有作品：

  1. 颜色驱动式物理漂移（Color-Driven Drift Physics）
     屏幕中心为具有质量、惯性与中心回拉弹性的"和声球"。玩家通过键盘
     D / F / J / K 四键分别对应红 / 蓝 / 绿 / 黄 四色音符节点；
     ── 每按对一个处于球体引力范围的彩色节点，不仅得分+音效，
        还会向该颜色对应的物理方向"推动"和声球：
            红 → +X 向右
            蓝 → -Y 向上
            绿 → -X 向左
            黄 → +Y 向下
     ── 这让传统节奏按键与即时物理走位策略深度耦合，迫使玩家在
        眼（节奏判断）、手（按键时机）、脑（走位规划）三者之间
        建立全新的协调关系，而不再是传统节奏游戏的纯时间轴反应。

  2. 四色不重复和弦连击（Rainbow Chord Chain）
     连续成功的 4 次激活若颜色各不相同（红-蓝-绿-黄的任意排列），
     即触发「CHORD ×4」四倍加成，鼓励玩家主动利用上一条中的
     漂移机制规划颜色顺序，同时兼顾走位安全与高倍率收益。

  3. 失谐度压力机制（Dissonance Pressure System）
     错过或误按累积"失谐度"100 点满即结束游戏。75% 以上触发
     红色高压警告闪烁，形成渐进难度与心理压力曲线，无需设置
     生命值或固定关卡即可获得无限期的自适应挑战感。

  4. 彩虹节点的负面清零与稀有奖励
     随机产生的闪烁彩虹节点，命中后立即 -60 失谐度、赠送 800
     基础分 + 彩色粒子爆发，成为玩家脱困与翻盘的关键锚点。

  以上 4 点机制的叠加构成本作品可区分于任何现有节奏/音游/消除类
  软件的独创性表达。


三、技术实现与主要文件
──────────────────────
  本作品为作者从零开发，未使用任何第三方游戏引擎或素材资源，
  全部图形、程序、音效均由作者程序化合成：

  ┌─────────────────────────────────────────────────────────┐
  │ 文件                         │ 作用                     │
  ├─────────────────────────────────────────────────────────┤
  │ harmonic-drift.html          │ 游戏主程序（单文件），     │
  │                              │ 包含 <canvas> 渲染、核心   │
  │                              │ 玩法循环、Web Audio 音乐   │
  │                              │ 合成、HUD/粒子/震动特效    │
  │ HarmonicDrift-v1.0.0.apk     │ Android 安装包，内嵌      │
  │                              │ 上述主程序                │
  │ android-src/                 │ Android 原生工程源代码：   │
  │   app/src/main/...           │   MainActivity.java       │
  │                              │   布局/主题/自适应启动图标 │
  │                              │   build.gradle.kts        │
  └─────────────────────────────────────────────────────────┘

  关键技术参数：
    ・渲染：HTML5 Canvas 2D Context，requestAnimationFrame 主循环
    ・音效：Web Audio API（OscillatorNode + GainNode 实时合成）
          四音 C5-E5-G5-B5，组成 C 大调大七和弦分解
    ・Android 端：AndroidX AppCompat + androidx.webkit，
          API 26 （Android 8.0）起步，目标 API 35
    ・屏幕：横屏锁定，沉浸式 Fullscreen Sticky，硬件加速
